# たんごクエスト

英単語を自分で調べて登録し、ゲーム感覚で覚えるスマホ用アプリです（英検・受験・日常、なんの単語でもOK）。
ログイン不要・無料。データはスマホの中（localStorage）にだけ保存されます。

## 使い方
1. **登録**：英単語を入力して「調べる」。辞書の結果から覚えたい意味にチェックし、日本語の意味を自分で入力して「保存」。
   「Weblioで見る」「英辞郎で見る」で日本語の意味を確認できます。辞書にない単語やオフラインのときは「自分で意味を追加」で手動登録できます。
2. **単語帳**：登録した単語の検索・並び替え・編集・削除。
3. **ゲーム**：フラッシュカード／4択クイズ（4単語以上で遊べる）／タイムアタック（60秒）。
   3回連続で正解すると「マスター」。間違えた単語は出やすくなります。
4. **設定**：データの書き出し・読み込み・全削除。**機種変更の前に必ず書き出してください。**

## ホーム画面に追加（アプリとして使う）
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：右上メニュー →「ホーム画面に追加」（または「アプリをインストール」）

一度開けば、オフラインでも登録済み単語のゲームができます（辞書検索だけはネット接続が必要）。

## 公開方法（GitHub Pages）
1. このフォルダの中身をGitHubのリポジトリの `main` ブランチ直下にpush
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` をスマホで開く

## 構成
`index.html` / `style.css` / `app.js` / `manifest.json` / `service-worker.js` / `icon-192.png` / `icon-512.png`
（ビルド不要の静的サイトです。辞書は [Free Dictionary API](https://dictionaryapi.dev/) を使用）

ローカルで試すとき：`python -m http.server 8000` → http://localhost:8000
